# Демо приложение

Демо приложение для демонстрации использования веб-компонентов.

## На что стоит обратить внимание

1. Размер приложения 23 Кб. Собрать приложение: `npm run build`.
2. Использование миксинов и переменных из [UI-kit](./src/my-app.scss).
3. Использование общих стилей для CSS нормализации в [приложении](./src/my-app.ts).
4. Наше приложение это просто кастомный тег [&lt;my-app&gt; в index.html](./index.html).
