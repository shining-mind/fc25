# styles/

Данный модуль содержит дополнительные стили, которые могут применяться в разных местах приложения.

## mixins.scss

Файл содержит миксины, которые могут использоваться в отдельных компонентах.
Для использования миксинов файл должен быть импортирован (они не доступны глобально).

## variables.scss

Файл содержит переменные, которые могут использоваться в отдельных компонентах.
Для использования переменных файл должен быть импортирован (они не доступны глобально).
