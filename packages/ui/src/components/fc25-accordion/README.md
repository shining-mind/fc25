# Fc25Accordion

Компонент аккордеона для отображения сворачиваемого контента с возможностью раскрытия и сворачивания элементов.

## Обзор

Аккордеон состоит из двух компонентов: основного контейнера `fc25-accordion` и элементов `fc25-accordion-item`. Поддерживает как одиночное, так и множественное раскрытие элементов. Каждый элемент может содержать произвольный контент и настраиваемый заголовок.

## Использование

### Базовое использование

```html
<fc25-accordion>
  <fc25-accordion-item label="Первый элемент">
    Содержимое первого элемента
  </fc25-accordion-item>
  <fc25-accordion-item label="Второй элемент">
    Содержимое второго элемента
  </fc25-accordion-item>
</fc25-accordion>
```

### С кастомным заголовком через слот

```html
<fc25-accordion>
  <fc25-accordion-item>
    <span slot="label">Заголовок с HTML</span>
    Содержимое элемента
  </fc25-accordion-item>
  <fc25-accordion-item>
    <span slot="label">
      <strong>Важный заголовок</strong>
      <span style="color: #666; font-size: 12px;"
        >с дополнительной информацией</span
      >
    </span>
    Содержимое с составным заголовком
  </fc25-accordion-item>
</fc25-accordion>
```

### Множественное раскрытие

```html
<fc25-accordion multiple>
  <fc25-accordion-item label="Элемент 1"> Содержимое 1 </fc25-accordion-item>
  <fc25-accordion-item label="Элемент 2"> Содержимое 2 </fc25-accordion-item>
</fc25-accordion>
```

### С предварительно раскрытым элементом

```html
<fc25-accordion>
  <fc25-accordion-item label="Раскрытый элемент" expanded>
    Этот элемент будет раскрыт по умолчанию
  </fc25-accordion-item>
  <fc25-accordion-item label="Свернутый элемент">
    Этот элемент будет свернут
  </fc25-accordion-item>
</fc25-accordion>
```

## API

### fc25-accordion

#### Атрибуты (Attributes)

| Атрибут    | Тип       | Описание                                              |
| ---------- | --------- | ----------------------------------------------------- |
| `multiple` | `boolean` | Разрешить раскрытие нескольких элементов одновременно |

#### Слоты (Slots)

| Слот      | Описание                                    |
| --------- | ------------------------------------------- |
| `default` | Элементы аккордеона (`fc25-accordion-item`) |

### fc25-accordion-item

#### Свойства (Properties)

| Свойство | Тип      | По умолчанию | Описание                      |
| -------- | -------- | ------------ | ----------------------------- |
| `label`  | `string` | `''`         | Заголовок элемента аккордеона |

#### Атрибуты (Attributes)

| Атрибут    | Тип       | Описание                      |
| ---------- | --------- | ----------------------------- |
| `label`    | `string`  | Заголовок элемента аккордеона |
| `expanded` | `boolean` | Состояние раскрытия элемента  |

#### События (Events)

| Событие                 | Тип данных          | Описание                                        |
| ----------------------- | ------------------- | ----------------------------------------------- |
| `accordion-item-toggle` | `CustomEvent<void>` | Испускается при переключении состояния элемента |

#### Слоты (Slots)

| Слот      | Описание                                                     |
| --------- | ------------------------------------------------------------ |
| `default` | Основное содержимое элемента аккордеона                      |
| `label`   | Кастомный заголовок элемента (альтернатива атрибуту `label`) |

### CSS Custom Properties

| Свойство                       | По умолчанию          | Описание                         |
| ------------------------------ | --------------------- | -------------------------------- |
| `--accordion-background-color` | `$background-primary` | Цвет фона аккордеона             |
| `--accordion-content-color`    | `$text-secondary`     | Цвет текста содержимого элемента |

## Примеры

### Различные типы контента

```html
<fc25-accordion>
  <fc25-accordion-item label="Простой текст">
    Обычное текстовое содержимое элемента аккордеона.
  </fc25-accordion-item>

  <fc25-accordion-item label="HTML контент">
    <p>Параграф с <strong>жирным текстом</strong></p>
    <ul>
      <li>Первый пункт списка</li>
      <li>Второй пункт списка</li>
    </ul>
  </fc25-accordion-item>
</fc25-accordion>
```

### Кастомные заголовки через слот

```html
<fc25-accordion>
  <!-- Заголовок с HTML элементами -->
  <fc25-accordion-item>
    <strong slot="label">Важная информация</strong>
    Содержимое с выделенным заголовком
  </fc25-accordion-item>

  <!-- Заголовок с несколькими элементами -->
  <fc25-accordion-item>
    <div slot="label">
      <span>Уведомления</span>
      <small> (3 новых)</small>
    </div>
    Новые уведомления и сообщения
  </fc25-accordion-item>

  <!-- Заголовок с подзаголовком -->
  <fc25-accordion-item>
    <div slot="label">
      <div>Основной заголовок</div>
      <small>Дополнительное описание</small>
    </div>
    Содержимое с составным заголовком
  </fc25-accordion-item>
</fc25-accordion>
```

### Кастомизация стилей

```html
<fc25-accordion
  style="--accordion-background-color: #f5f5f5; --accordion-content-color: #666;"
>
  <fc25-accordion-item label="Элемент с кастомными цветами">
    Содержимое с измененными цветами фона и текста.
  </fc25-accordion-item>
</fc25-accordion>
```

## Поведение

### Режим одиночного раскрытия (по умолчанию)

- Только один элемент может быть раскрыт одновременно
- При раскрытии нового элемента предыдущий автоматически сворачивается

### Режим множественного раскрытия

- Несколько элементов могут быть раскрыты одновременно
- Включается атрибутом `multiple`

### Анимация

- Плавная анимация раскрытия/сворачивания содержимого
- Поворот иконки стрелки при изменении состояния
- Переходы для opacity и visibility контента
